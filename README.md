# GESTION DE MAGAZIN INFORMATIQUE

_Ce projet vise a simuler le fonctionnement d'un magazin informatique en s'appuiant sur 2 technologies principales:_

**- Python3 (Programmation)**
**- sqlite3 (Base de donnees)**

# INFORMATIONS GENERAUX

l'interface graphique est realisee a l'aide du module "Tkinter" de Python3


# DETAILS DE FONCTIONNEMENTS

Le programme principale de notre projet est "main.py". Il s'agit d'un "Dashboard" qui nous dirige vers d'autres programmes selon l'action choisie dans le Dashboard.
